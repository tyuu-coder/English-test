# 英単語テスト対策ノート（Vocab Typing Drill）

日本語の意味を見て英単語のスペルをタイピングで練習できる、単体HTMLの単語学習アプリです。ビルド不要・サーバー不要で、ファイルをブラウザで開くだけで動作します。

## 特徴

- **レッスン管理**：単元・回ごとに複数の単語リストを登録可能
- **表を貼り付けて単語登録**：Excel/スプレッドシートの「英単語」「意味」列をそのままコピー＆ペースト
- **フラッシュカード学習**：タップでカードを裏返して意味→英単語を確認、「覚えた／もう一度」で仕分け
- **タイピングテスト**：日本語の意味を見て英単語のスペルを入力、複数の意味（同義語）にも対応
- **わからない単語のスキップ**：スキップした単語は間違い扱いで記録され、後で復習できる
- **苦手単語の自動集計**：間違えた回数が多い単語を自動でリストアップし、まとめて復習可能
- **練習履歴**：レッスンごとに過去の練習結果を記録し、間違えた回だけ再挑戦できる
- **先生用管理画面**：暗証番号で保護された管理画面からレッスンを編集し、`lessons.json`として書き出して公開（簡易的な目隠しであり、強固な認証ではありません）

## 使い方

1. `vocab_typing_drill.html` と `lessons.json` を同じフォルダに置いてGitHub Pagesなどで公開する（ローカルでブラウザで開くだけでも動作します）
2. 生徒画面の「先生用」から管理画面に入り、暗証番号を設定してレッスンと単語を登録
3. 編集後は「`lessons.json` を書き出す」でファイルをダウンロードし、リポジトリの`lessons.json`を置き換えてコミット・プッシュして公開（詳しくは下記）
4. 生徒はレッスンを選び、フラッシュカードまたはテストで練習

## データの保存について

生徒がバラバラの端末からアクセスする前提のため、レッスン内容（単語リスト）はブラウザの保存ではなく、リポジトリに含まれる **`lessons.json`** から読み込みます。GitHub Pagesなどで公開すると、この`lessons.json`の内容が全生徒に共通で配信されるため、「先生が登録したレッスンはどの端末からでも解ける」という前提を満たせます。

一方、**練習履歴・苦手単語の記録は、各生徒の端末のブラウザ内（`localStorage`）に保存**されます。これは生徒本人が自分の学習状況を振り返るためのもので、他の生徒や先生と共有されるものではありません（出席番号などによる「誰が何回取り組んだか」をクラス全体で共有する機能は、複数端末では正しく機能しないため実装していません）。

### レッスンを公開する手順（先生用）

1. サイトの生徒画面の「先生用」から管理画面に入り、暗証番号でログイン
2. レッスンを追加・編集（この時点ではまだこの端末の下書きとしてのみ保存されています）
3. 「`lessons.json` を書き出す」ボタンでファイルをダウンロード
4. ダウンロードしたファイルでリポジトリの `lessons.json` を置き換え、GitHubにコミット＆プッシュ
5. GitHub Pagesに反映されると、すべての生徒がその内容を練習・テストできるようになります

管理画面には、公開中の`lessons.json`を読み込み直すボタンや、書き出したファイルを読み込むボタンもあるので、別の端末から編集を再開することもできます。

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）
- レッスン内容：リポジトリ同梱の `lessons.json`（全員に共通配信）
- 練習履歴など個人の記録：ブラウザの `localStorage`（端末ごと）
- 外部フォント：Google Fonts（Yomogi, Zen Maru Gothic, JetBrains Mono）
